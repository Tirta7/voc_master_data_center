# BilliardMaster Landing Page

Landing page promosi profesional untuk aplikasi Billing Billiard.

## Fitur Utama Landing Page:
- **Hero Section Modern**: Menggunakan grafis premium AI-generated.
- **Value Proposition Card**: Menjelaskan IoT Lampu, POS Cafe, Member QR, dan Analytics.
- **Tabel Karakteristik (Battle Competitor)**: Menunjukkan kenapa sistem ini jauh lebih unggul dibanding manual atau sistem lain.
- **Social Proof**: Testimoni dari Owner & Manager Billiard.
- **Conversion Focused**: CTA WhatsApp dan penawaran terbatas.

## Cara Menggunakan:
1. Buka folder `landing-page`.
2. Klik kanan pada `index.html` dan pilih **Open with Browser** (Chrome/Edge).
3. Untuk mengubah nomor WhatsApp, edit file `index.html` pada bagian `href="https://wa.me/your-number"`.
